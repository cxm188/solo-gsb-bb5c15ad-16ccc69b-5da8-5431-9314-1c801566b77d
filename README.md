# 圆筒包装接缝避让

输入筒体周长、接缝安全宽度与若干毫米制印刷保护区，系统按周长归一化跨零点区间、合并禁用旋转范围，列出全部可行角度段，默认选择**距禁用边界最远、角度最小**的旋转量；Canvas 同步预览接缝与保护区，拖动时吸附到最近可行位置；无解时展示覆盖整圈的禁用区间链。

## 启动

```bash
docker compose up --build
```

启动时容器内自动完成 `npm install` 依赖安装与服务初始化。

## 配置（可选）

通过环境变量或 Compose 覆盖：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `3000` | 服务监听端口（容器内） |
| 宿主机端口 | `3000` | 在 `docker-compose.yml` 或用 `PORT=xxxx docker compose up --build` 修改 |

无数据库等外部依赖。

## 访问

启动后打开：<http://localhost:3000>
